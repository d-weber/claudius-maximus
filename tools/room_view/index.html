Sheets on disk
How it works The page asks tools/room_view.py to run the real room code (the firmware's C++, built for the host) for the chosen state and plays the frames at 12 fps. Refresh regenerates the sprite tables from firmware/assets/sprites, recompiles, and re-renders. Auto-refresh watches the sheets' modification times, so saving from Photoshop (indexed mode, palette.gpl) updates the view within a few seconds. A broken sheet shows the converter's error here.
